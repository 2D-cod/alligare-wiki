# Versionamento do vault com Git

Cada commit é um ponto de restauração. Antes de um trabalho grande do agente, commit; se ele bagunçar, volta-se a qualquer ponto. O autor pede ao próprio Hermes: "inicialize a raiz como repositório Git e faça um commit-base". O plugin Obsidian Git permite commitar pelo app.
Para a Alligare: o vault tem dados de clientes e de finanças, então qualquer repositório remoto deve ser **privado** e o snapshot do dossiê deve ficar de fora. Ver [[controle-de-acesso-ao-vault]] e [[roteiro-de-implantacao]].
